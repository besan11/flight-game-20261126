**SKYFERRY** — fly the Kite-9 courier plane through six sorties over a
seeded island archipelago: thread the ring course, drop supply crates on
the beach circle, land the short north strip, cross a storm front, fly the
night mail to the lighthouse, and pick up a stranded hiker. Chase camera,
a twelve-system glass cockpit (airspeed, altitude, heading tape, attitude
ball, vertical speed, fuel, throttle, flaps, gear, wind, timer, score),
fuel and airframe management, wind shear and gusts, graded landings, and
synthesized engine and wind audio. Everything runs offline from static
files — no network, no account.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Pick a sortie with
the mouse or keys 1–6. Fly with ↑/↓ or W/S (pitch), ←/→ or A/D (bank),
Shift/Ctrl (throttle), Space (drop a crate), G (flaps), L (gear), B
(brake), P (pause), T (restart the sortie).
